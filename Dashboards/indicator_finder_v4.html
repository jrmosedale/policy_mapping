Climate–Nature Indicator Finder

A searchable catalogue of 985 environmental indicators drawn from nine UK and international frameworks (EIF, CCC, JNCC UKBI, State of Nature, EEA, BIP, IPBES, CBD GBF, UN SDG). For each indicator it shows how sensitive it is to climate, and the policy context that uses it.

Climate score

Each indicator carries a 0–3 climate-relevance score — none / low / medium / high — for how far its measured quantity depends on climate variables. The coloured badge on each result and the sidebar filter use the same scale.

Finding indicators

  • Filter (left) by sector, NCF category, framework, climate score, geographic scope, or policy-context type. Sector uses the workbook's 14-class Policy_Sector vocabulary — the same classes as the Governance Diagram, so the two dashboards can be filtered in step. An indicator may carry up to three.
  • Search free-text across name, framework, type, goal and NCF.
  • Sort (top of the list) by climate score, name or framework.

Policy context (right panel)

Click any indicator to see its detail and its governance links — the legislation, bodies and policies it informs. A ★ / green dot marks a designated monitoring indicator for that instrument; an open dot marks a policy-relevant link. Each link offers ↗ source (the official page) and ⬡ diagram, which opens that record as the focus node in the Governance Diagram in a new tab.

Data: canonical workbook indicators_climate_nature.xlsx. Framework abbreviations are listed in the Framework filter.
